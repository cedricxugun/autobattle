# 0.6 十人口与传说

本次解决三个问题：人口被硬编码为8、品质在界面中不明显、5费卡缺乏改变阵容走向的能力。

## 参考与范围

2026-10-16查阅 [DOTA AUTO CHESS官方创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=1613886175) 及[官方更新记录](https://steamcommunity.com/sharedfiles/filedetails/changelog/1613886175)，当时最近可见更新为10月15日。该作品与独立《多多自走棋》区分处理。官方主页标明8×8棋盘、1–8名玩家；本项目目前保留6×8物理格位，没有宣称棋盘或规则一比一复制。

此次采用成熟自走棋的进程设计思路：人口与搜卡取舍、有限共享卡池、品质分层、后期核心与针对性反制。下面的经验、概率、伤害均为本项目数值，不是未经核实冒充最新版DOTA AUTO CHESS的数值。

## 经济与品质

8人参赛，等级上限10，上阵上限10，备战席9；二星3张、三星9张。原有共享池35/30/25/18/12张，每次购买、刷新、出售、淘汰都按库存处理。低等级卡池耗尽不会越级刷出传说。

每系9角色：1/2/3/4/5费数量2/2/2/2/1，对应普通/精良/稀有/史诗/传说。品质是固定角色稀有度；星级是合成等级，两者分别显示。

## 六张传说

| 角色 | 核心作用 | 反制 |
|---|---|---|
| 公理之龙 | 固定区域群伤禁足，全队按战前公理护盾/净化治疗/技能强化 | 分散、打断证明 |
| 时空织者 | 回复近期损血并净化，全体救场，敌群时停 | 持续伤害、回卷后再爆发 |
| 平衡奇美拉 | 固定4秒反应堆，百分比伤害并轮换酸电热 | 离开区域、分散前排 |
| 文明方舟 | 每队每战至多复活一名核心，另召两名8秒护卫 | 控制方舟、范围清援军 |
| 万卷龙 | 三幕范围爆发，末幕变书，语文施法种类增加伤害 | 打断吟唱/连段、控制免疫、分散 |
| 法典巨龙 | 证据增伤、禁足，领域内敌人首次尝试施法被打断 | 普攻阵容、离开领域 |

各技能具体数值在图鉴中显示；角色与知识概念属于游戏改编。复活不增加卡池占用或羁绊计数，召唤物不释放传说技能。领域不会沉默己方。

## 验证

`test-endgame.cjs`覆盖十人口、满员替换、满级不扣款、各系品质、低阶池耗尽不越级、AI升10、六种大招实际效果与蓄力中断、单次复活、变书净化、敌方领域打断。

`test-native.cjs`检查共享池守恒、三种AI难度完整对局、观战、掉落、合星、存档；`test-presentation.cjs`遍历63种角色/野怪演示及20单位演练。Godot测试覆盖地面拾取、原生拖拽交换/上下场、六种大招实际目标中心/半径、暂停、结束清理与观战切换。GPU实际运行检查了准备界面、单技能演示与10对10混战。

`measure-endgame.cjs`是可重复的固定阵容对照，不是全游戏平衡证明。每名传说18组配对，共216场：同一队伍同一随机种子，最后一个位置由同系二星4费替换成一星5费，其余位置不变。使用正式属性与冷却，没有演示专用加血。对手包括六系，原始数据见[JSON](balance/endgame-0.6.json)。
